# القضية 03: تنفيذ عن بُعد

**المستوى:** متوسط

## السيناريو

ظهرت على جهاز أحد الموظفين أوامر استطلاع لم يكتبها، وأداة EDR تشير إلى سلسلة عمليات غير معتادة.

## الأدلة

`evidence/Sysmon.evtx`

## ابدأ من هنا

```
hunt cases/case-03
chainsaw search "cmd.exe" cases/case-03/evidence -q
```

## الأسئلة

1. ما اسم الجهاز والحساب المستخدم؟
2. ما العملية الأب (Parent Process) التي شغّلت `cmd.exe`؟ ولماذا هي مريبة؟
3. ما الأمر الاستطلاعي الذي نفّذه المهاجم؟
4. إلى أين تُكتب مخرجات الأوامر؟
5. شكل الأوامر يكشف الأداة المستخدمة. ما هي؟
6. ما تقنية MITRE ATT&CK المطابقة؟
7. اكتب قاعدة كشف بسيطة (بالمنطق أو بصيغة Sigma) تلتقط هذا السلوك.
