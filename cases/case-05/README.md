# القضية 05: تفريغ ذاكرة عملية

**المستوى:** متوسط

## السيناريو

نبّه نظام المراقبة على استخدام أداة نظام مدمجة في ويندوز بطريقة غير معتادة، مع إنشاء ملف جديد داخل مجلد النظام.

## الأدلة

`evidence/Sysmon.evtx`

## ابدأ من هنا

```
hunt cases/case-05
chainsaw dump cases/case-05/evidence/Sysmon.evtx -q | less
```

## الأسئلة

1. ما الملف النصي (Script) الذي بدأ السلسلة؟ وبأي برنامج شُغّل؟
2. ما أداة النظام (LOLBin) والمكتبة المستخدمة لتفريغ الذاكرة؟
3. ما رقم العملية المستهدفة واسمها؟
4. أين حُفظ ملف التفريغ؟ ولماذا امتداده مضلل؟
5. ما العملية الأب لأداة التفريغ؟ وماذا يدل ذلك على طريقة التنفيذ؟
6. لو كانت العملية المستهدفة `lsass.exe`، ما الخطر؟ وما تقنية MITRE ATT&CK المطابقة؟
7. ما قيمة `GrantedAccess` في حدث الوصول للعملية؟ وماذا تعني؟
