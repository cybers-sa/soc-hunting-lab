# القضية 07: قناة تحكم مخفية

**المستوى:** متقدم

## السيناريو

جهاز داخلي يرسل عددًا كبيرًا من طلبات DNS لنطاق واحد خلال دقيقة واحدة، ولا توجد حركة ويب ظاهرة.

## الأدلة

`evidence/traffic.pcap`

## ابدأ من هنا

```
zeek-run cases/case-07/evidence/traffic.pcap
cd cases/case-07/results/zeek
cat dns.log | zeek-cut ts id.orig_h id.resp_h query qtype_name answers
```

## الأسئلة

1. ما عنوان IP للجهاز المصاب؟ وما خادم DNS الذي يستخدمه؟
2. ما النطاق المشبوه؟
3. ما نوع سجل DNS المستخدم؟ ولماذا يفضله المهاجمون؟
4. كم طلبًا من هذا النوع أُرسل؟
5. ما أول طلب من هذا النوع؟ ولأي خادم DNS أُرسل؟
6. انسخ محتوى الرد الأول وحلّله: بأي لغة كُتب؟ وماذا يفعل؟
7. فك ترميز Base64 لأحد الردود التالية. ماذا تجد؟
8. ما تقنيات MITRE ATT&CK المطابقة؟
9. اذكر ثلاثة مؤشرات اختراق (IOCs) من هذه القضية.
